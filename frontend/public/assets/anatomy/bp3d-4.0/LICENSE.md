# BodyParts3D-derived assets

The GLB files in this directory are derived from **BodyParts3D 4.0** (PART-OF tree,
99 % polygon reduction) by the MEDVERSE asset pipeline (`pipeline/bodyparts3d/build.py`):
coordinate conversion to metres / Y-up, regrouping by body system, and meshopt compression.
